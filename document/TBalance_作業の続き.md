## 現在の目的

TBalanceは、TeaMerry Forestの画像配置、PC/Mobile別配置、当たり判定、ボタン、テキスト、メモ、Markup、WITH AI共有を見た目で調整するための編集ツール。

最初の大きな目的だった「PC/Mobileの当たり判定を見える化して、配置を直感的に編集する」は一通り到達済み。
現在は、画像編集ソフトに近い使い勝手と、新規ページ作成・絵コンテ用途にも広げるための土台を整えている。

### Ver.1区切り

2026-08-24時点で、TBalance Ver.1は「配置・当たり判定・PC/Mobile確認・WITH AI共有」までを到達範囲として区切る。

Ver.1の目的:

- TeaMerry Forestのページを見た目で配置確認する。
- PC / Mobile別に背景、レイヤー、当たり判定を調整する。
- 当たり判定を緑枠で見える化する。
- リル、吹き出し、ボタン、リンク先を配置確認する。
- WITH AIでCodexへ現在画面と編集状態を共有する。
- Codex側で共有状態を読み、公開用HTML/CSS/JSへ反映する。

Ver.1で成立した実績:

- 星風テラス夜のPC / Mobile背景をTBalance上で調整した。
- リル、吹き出し、戻るボタン、願い星を書く、今日のほっこりの当たり判定を確認した。
- WITH AI共有でCodexが現在画面とレイヤー情報を確認した。
- Codex側で `observatory.html` / `observatory.js` / `css/observatory.css` と `docs/` 側へ反映した。
- GitHub Pagesへpushし、公開ページで表示確認した。
- 今日のほっこりは、既存の星型ランダム表示システムを残す方針に戻した。

Ver.1で未接続のまま残すもの:

- Final Previewの本格処理
- Publishの自動公開
- TBalance形式から公開HTML/CSS/JSへの自動生成
- 画像・動画の本格最適化
- 既存HTML/CSS/JSの自動解析と再反映

重要な判断:

TBalance Ver.1では、TBalance内の編集結果をそのまま自動公開しない。
公開反映は、TBalanceの共有情報をCodexが読み取り、既存の公開コードを壊さないように必要箇所だけ反映する。

タグ:

- `v1-tbalance-layout-share`

このタグを、Ver.1の区切り地点として扱う。

### 新規キャンバス作成

`ファイル → 新規` で「新規キャンバス作成」ダイアログを出すようにした。

指定できる項目:

- ファイル名
- 幅(px)
- 高さ(px)
- プリセット
- 背景タイプ
- 空白から始める / 画像をすぐ読み込む

プリセット:

- TeaMerry PC 1920x1080
- TeaMerry Mobile 1080x1920
- 動画 16:9
- 動画 9:16
- 正方形
- カスタム

Canvas / Stageをレイヤーとは別の固定土台として扱う方向で実装。
透明背景の場合は編集画面ではチェック風の背景で見えるようにし、書き出しでは透明として扱う。

### ページ名変更

ヘッダー3段目のページ名をダブルクリックすると、直接名前を編集できるようにした。

操作:

- ダブルクリックで編集
- Enterまたはフォーカス外で確定
- Escでキャンセル
- 空欄の場合は「未命名」

### WITH AI共有履歴

WITH AIの共有更新に履歴を追加した。

仕様:

- 共有更新ごとに、現在状態と画面画像を履歴へ保存する。
- 履歴はページごとに直近5件まで保存する。
- 6件目以降は古い履歴から自動削除する。
- 履歴を復元した場合、復元元を新しい最新版として共有履歴へ追加する。
- 共有履歴は「何をAIに見せたか」の記録。
- 質問内容やAI返答ログは、共有履歴とは別枠で扱う。

保存先:

- `tools/tbalance/ai-bridge/current-state.json`
- `tools/tbalance/ai-bridge/current-view.webp`
- `tools/tbalance/ai-bridge/history/`

`history/` はGit管理対象外。

### 赤ペン指示のPC / Mobile混線補正

WITH AI共有で、PC / Mobile同時表示時に赤ペン指示が崩れる症状を確認した。

確認できた症状:

- 赤ペン指示レイヤーが2つ存在。
- 片方はMobile側レイアウトにPCサイズ `1920x1080` が入っていた。
- もう片方はPC側レイアウトにMobileサイズ `1080x1920` が入っていた。
- どちらも `visibilityMode: both` のため、同時表示時に別画面用の赤ペンが見えていた。

対応:

- 新規の赤ペン指示は、描いた画面だけに表示する。
- PCで描いた赤ペンはPC専用、Mobileで描いた赤ペンはMobile専用にする。
- 既存データでPC / Mobileのレイアウトが逆に混ざった赤ペンは、再描画時に自動補正する。
- トラブルシュートにも症状と対処を記録した。

## WITH AIの現在仕様

WITH AIは、CodexがTBalanceの現在状態を手作業のスクショ添付なしで確認するための共有機能。

現在は、WITH AIをONにして「共有更新」を押すと、localhostブリッジ経由で以下を共有する。

- 現在画面
- ページ名
- PC / Mobile
- キャンバスサイズ
- Stage情報
- レイヤー一覧
- 選択中レイヤー
- 当たり判定
- Markup
- 自分メモ

AIが常時解析するわけではなく、共有更新した時点の状態をCodexが読みに行く方式。
共有履歴はページごとに直近5件まで見返せる。

## 現在の注意点

- デスクトップ版Codex、VS Code + Codex、Android + Termius + Codex CLIは、チャット履歴は自動共有されない。
- 同じプロジェクトフォルダを触っていれば、ファイル変更は共有される。
- 調査結果や次にやることは、このファイルに残す。
- 大きな節目だけは別途アーカイブしてもよい。
